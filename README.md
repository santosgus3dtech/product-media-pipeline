# Product Media Pipeline

A reproducible image-processing pipeline for marketplace-ready product media. The included assets are generated fixtures, not commercial catalog images.

![Normalized synthetic product contact sheet](docs/images/contact-sheet.png)

## What it does

- Discovers JPEG, PNG and WebP assets.
- Removes empty background margins and centers the subject.
- Normalizes every image to a consistent square canvas.
- Uses SHA-256 and a visual difference hash to identify duplicates.
- Applies deterministic, filesystem-safe output names.
- Writes an auditable JSON manifest and contact sheet.
- Keeps input and output dimensions for traceability.

## Demo

```bash
python -m pip install -e .
python scripts/generate_demo_assets.py
python -m media_pipeline.cli examples/input generated
```

## Test

```bash
python -m pip install pytest
pytest -q
```

## Privacy boundary

No private catalog, marketplace account, customer upload, brand photo, session or production directory is included. The sample product art is generated by the repository itself.
